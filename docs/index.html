YOUR PLACE ON THE INTERNET

Bring WatchRoom home.

Self-host with Docker.
Choose a domain or an IP.

⌘QUICK START · UBUNTU / DEBIAN

A few commands to movie night.

The interactive installer sets up Docker, asks how friends will reach the server, and checks that WatchRoom is running.

# Get WatchRoom
git clone https://github.com/MohammadAliMehri/watchroom.git
cd watchroom

# Start the friendly setup
sudo bash deploy.sh

Have Docker ready? See the manual Compose guide.

◎CHOOSE YOUR ADDRESS

Domain or IP?

✦
Domain · recommendedAutomatic HTTPS with Caddy. Point DNS to your server and open ports 80 + 443.
↗
Public IPQuick to try over HTTP. Open port 80; traffic is not encrypted.
Small server?

1 CPU / 1 GB can work for a tiny room with direct-play media. MKV conversion needs more breathing room. See server sizing →

SETTINGWHAT IT DOES
DOMAINHostname Caddy uses to provide HTTPS.
ALLOWED_ORIGINSExact public URL allowed to connect to the app.
PORTLocal Express port. Defaults to 3000.
DB_PATHSQLite location for accounts, rooms, and playlists.
MEDIA_DIRTemporary HLS and subtitle conversion cache.
